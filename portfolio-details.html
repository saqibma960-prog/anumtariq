Android application with user accounts and planning modules

Final Year Project (CS619) at Virtual University of Pakistan: an Android app with user accounts, planning modules, and local data storage. I used my coursework in software engineering, databases, and visual programming to structure the app, store user data, and keep the main flows simple enough for daily use.

Project Overview

The brief, the approach, and what came out of it

The Brief

CS619 required a complete Android application built and documented independently: a real problem, a working app, and a defence of every design decision made along the way.

The Approach

I mapped the screens and the data model first, then built user accounts, the planning modules, and local storage so the app stayed usable without a constant connection.

The Outcome

A working application delivered and defended for my final year, and the first project where I owned the full cycle from requirements through to documentation.

What I Handled

Every part of this project was built solo

Phase 01

Requirements & Scope

Defined what the app needed to do, which screens were essential, and where data had to persist between sessions.

Phase 02

Data Model

Designed the local database structure for user accounts and planning records, applying the DBMS coursework from my degree.

Phase 03

Application Build

Built the Android screens and navigation, wired them to storage, and kept the main flows short enough for daily use.

Phase 04

Testing & Documentation

Tested the main paths, fixed the issues that surfaced, and wrote the full project documentation required for the CS619 submission.
